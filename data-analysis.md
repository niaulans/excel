# 📊 Data Analysis Workflow

| Stage | Step Name                       | Goal                                     | Activities                                                                                                                                                                                                                                                                                                                                                                                                                                   | Tools / Examples                             |
| ----- | ------------------------------- | ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| 1     | Understand the Business         | Align analysis with business needs       | - Identify business questions <br> - Understand sales goals (e.g. increase revenue, reduce churn) <br> - Define KPIs (e.g. total sales, AOV, conversion rate) <br> - Identify end users (e.g. sales manager, C-level)                                                                                                                                                                                                                        | Notion, Docs, Business Brief                 |
| 2     | Data Collection                 | Gather all relevant data sources         | - Collect sales data <br> - Include product, customer, promotion datasets <br> - Extract from database, CSV, Excel, or API <br> - Ensure date range consistency                                                                                                                                                                                                                                                                              | SQL, Excel, Python (pandas), API             |
| 3     | Data Cleaning                   | Prepare clean and reliable data          | - Remove duplicates <br> - Handle missing values <br> - Standardize formats (date, numeric) <br> - Normalize text (lowercase, trim, remove special chars) <br> - Fix typos <br> - Detect outliers <br> - Validate relationships (e.g. total = price × qty) <br> - Create new features (e.g. total_price) <br> - Ensure unique keys <br> - Merge datasets <br> - Recheck data types <br> - Export cleaned file <br> - Document cleaning steps | Python (pandas), Excel, Power Query          |
| 4     | Exploratory Data Analysis (EDA) | Explore patterns and trends              | - Generate summary statistics <br> - Identify top-selling products/customers <br> - Analyze trends by time/region/category <br> - Visualize outliers and anomalies <br> - Explore data distributions                                                                                                                                                                                                                                         | Excel Charts, Seaborn, Matplotlib, Power BI  |
| 5     | Insight Extraction              | Derive business-relevant findings        | - Highlight key trends and anomalies <br> - Correlate changes with campaigns or seasonality <br> - Explain causes of performance changes <br> - Prioritize actionable insights                                                                                                                                                                                                                                                               | Jupyter Notebook, Docs, Markdown             |
| 6     | Visualization / Dashboard       | Communicate insights visually            | - Build KPI dashboards <br> - Add filters for time/product/region <br> - Use effective charts and visuals <br> - Present data in user-friendly format                                                                                                                                                                                                                                                                                        | Power BI, Tableau, Looker Studio             |
| 7     | Recommendation                  | Suggest actions based on insights        | - Propose business actions <br> - Recommend focus products or regions <br> - Suggest pricing/inventory/promo strategy <br> - Forecast expected outcomes                                                                                                                                                                                                                                                                                      | Strategy Brief, Slide Deck, Report           |
| 8     | Communication                   | Present insights clearly to stakeholders | - Summarize key insights <br> - Emphasize business impact <br> - Tell a clear story (problem → insight → solution) <br> - Prepare for questions and feedback                                                                                                                                                                                                                                                                                 | PowerPoint, Google Slides, Executive Summary |
